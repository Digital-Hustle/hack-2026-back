# Эталоны и ошибки

- [certis-api](https://github.com/DanyaChetvyrtov/certis-api): feature-first, application/command/query, refresh-семейства, миграции, архитектурные проверки.
- [sueta-rnd-back](https://github.com/Digital-Hustle/sueta-rnd-back), event-ms: контроллер-интерфейс/реализация, DTO records, MapStruct. Событийную инфраструктуру не копировать.
- [hackathon-spring-2026-backend](https://github.com/Digital-Hustle/hackathon-spring-2026-backend): исторические замечания, не эталон всего приложения.

Эти назначения взяты из документации исходного проекта; код/лицензии/commit перед копированием проверить. Не приписывать репозиторию непроверенную готовую реализацию.

Не повторять: секреты в git; доступ к чужому ресурсу без scope; подделываемый клиентом X-User-Id; токен, принятый не по назначению; пропущенные тесты, выдаваемые за успешные; ArchUnit на пустых пакетах; разные форматы ошибок; отладочный код входа в production; документация, расходящаяся с реальным поведением.

Решение текущего проекта против подмены контекста: gateway удаляет клиентские заголовки и ставит проверенные, backend закрыт сетью. Повторный JWT в каждом сервисе не вводится.
